# Spec Delta

## ADDED Requirements

### Requirement: 直接计算四则算式
启动器 SHALL 在用户输入由数字、小数、`+`、`-`、`*`、`/` 和括号构成的完整四则算式时，按常规优先级在本机即时求值。查询须包含至少一次四则运算，并允许负数和空白。完整且可求值的算式 SHALL 产生一条结果。无效输入 SHALL 继续使用普通搜索。

#### Scenario: 输入乘法后直接显示结果
- **WHEN** 用户输入 `100*2`
- **THEN** 第一行显示 `200`，无需按回车或输入等号

#### Scenario: 按优先级和括号计算小数
- **WHEN** 用户分别输入 `2+3*4` 和 `(2+3)*0.5`
- **THEN** 启动器分别立即显示 `14` 和 `2.5`

#### Scenario: 非算式保留搜索行为
- **WHEN** 用户输入 `100*`、`1/0`、`100` 或 `1Password`
- **THEN** 启动器继续正常搜索，不展示算术结果

### Requirement: 将美元换算为人民币
完整查询为 `$` 加非负十进制金额时，启动器 SHALL 使用 Twelve Data 最新可用的 `USD/CNY` 报价，在本机将美元金额换算成人民币并显示两位小数及报价时间。需要新报价时 SHALL 异步获取，报价请求只发送固定货币对及认证信息。输入变化后 SHALL 只显示对应当前金额和配置的结果。

#### Scenario: 查询美元金额
- **WHEN** 用户输入 `$1`，Twelve Data 返回汇率 `6.6789` 和报价时间
- **THEN** 第一行显示 `¥6.68`，并标明该报价的时间

#### Scenario: 连续修改金额
- **WHEN** `$1` 的报价请求未完成，用户继续输入得到 `$12.50`
- **THEN** 报价返回后按 `$12.50` 换算，不显示 `$1` 的换算金额

#### Scenario: 等待报价时改为普通搜索
- **WHEN** 用户输入 `$1` 后，在报价返回前将查询改成 `1Password`
- **THEN** 启动器继续搜索 `1Password`，迟到的报价不会替换结果或抢占选择

### Requirement: 在客户端配置 Twelve Data API Key
Invoker SHALL 在「设置 → 通用 → 汇率」提供遮挡输入框，让用户填写、更换或清除自己的 Twelve Data API Key。Invoker SHALL 沿用本机密钥配置文件保存该 Key，与 AI 和 DeepL 的 Key 独立，兼容缺少汇率字段的旧配置。只向 Twelve Data 官方 HTTPS 接口发送汇率 Key，且不将其写入源代码或日志。

#### Scenario: 保存或更换汇率 Key
- **WHEN** 用户输入自己的 Key 或替换已有 Key，再发起美元换算
- **THEN** 请求使用当前 Key，重启后仍能读取该 Key，已有的 AI 和 DeepL Key 保持原值

#### Scenario: 未配置或清除 Key
- **WHEN** 旧配置缺少汇率字段，或用户清除 Key 后输入 `$1`
- **THEN** 结果区提示在设置中填写 Key，不发送汇率请求。算术、应用和命令搜索仍可使用

### Requirement: 复制计算和换算结果
启动器 SHALL 将有效计算结果放在命令和应用之前，沿用结果选择机制。回车、小键盘回车和点击选中计算结果 SHALL 将显示的数值以纯文本复制到剪贴板，然后关闭启动器。复制内容 SHALL 仅包含数值，计算结果不计入应用或命令使用统计。

#### Scenario: 复制算术结果
- **WHEN** 用户输入 `100*2`，选中 `200` 并按回车
- **THEN** 剪贴板收到 `200`，启动器关闭

#### Scenario: 复制人民币金额
- **WHEN** 用户点击显示为 `¥6.68` 的换算结果
- **THEN** 剪贴板收到 `6.68`，启动器关闭

## MODIFIED Requirements

### Requirement: 明确展示结果类型和状态
应用结果 SHALL 显示名称和应用图标，不显示所在路径，悬停提示也不得显示路径；图标不可用时使用通用图标。命令 SHALL 保留原描述、图标及快捷键提示。搜索框提示 SHALL 为“搜索命令或应用”。扫描完成且没有匹配结果时 SHALL 显示“没有匹配的命令或应用”，有效美元查询的等待、配置或获取失败状态使用对应的汇率提示。汇率状态 SHALL 不可执行。

#### Scenario: 同名应用不展示路径
- **WHEN** 查询返回两个同名应用
- **THEN** 两行均展示各自名称和图标，不在结果或悬停提示中显示路径，选择某行只执行其对应应用

#### Scenario: 无匹配结果
- **WHEN** 扫描已完成且查询既不匹配命令或应用，也没有计算结果或汇率状态
- **THEN** 显示无结果提示，不保留隐藏的选中项，按回车不执行任何动作

#### Scenario: 等待汇率或获取失败
- **WHEN** 有效美元查询正在取报价，或由于网络、认证、额度等问题无法取得可用报价
- **THEN** 显示等待或失败提示，提示不可选中或执行。在没有其他匹配结果时，按回车不复制任何内容，也不关闭面板
